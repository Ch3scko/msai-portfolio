Current Projects

Energy Intelligence Platform

How do historical energy trends differ between U.S. states? I built a Python and Streamlit application with Pandas and Plotly to compare states, filter energy indicators and years, and explore a U.S. map. The app loads a bundled demonstration dataset, energy_sample.csv, and accepts compatible CSV uploads.

Model decision: Five-year projections use linear regression on year. The project documentation reports that Random Forest performance deteriorated with temporal validation, so I present the output as an experimental trend projection rather than a validated forecast.

Cloud-Based Energy Analytics Pipeline on AWS

I built a Python and AWS pipeline for historical U.S. energy consumption data from the Energy Information Administration's State Energy Data System (SEDS). It moves data through Amazon S3, PySpark cleaning and aggregation, and DynamoDB storage, with Plotly visualizations for state-level exploration.

Technical detail: DynamoDB records use state and year as their keys. The project compares linear regression, decision tree, and Random Forest models for Alaska's energy consumption using Spark MLlib. The README reports the lowest RMSE for Random Forest; that comparison alone does not establish future forecasting reliability.

Customer Sentiment Intelligence

I built a Python and PyTorch pipeline to classify IMDb movie reviews as positive or negative. Evaluation uses reviews from the separate IMDb test split.

Held-out results: 79% accuracy and 77.56% F1. For context, always predicting negative would achieve 51.2% accuracy on this test subset. A TF-IDF and logistic regression comparison is not documented.

Limits: The notebook lists validation data, early stopping, and architecture comparisons as future improvements.
