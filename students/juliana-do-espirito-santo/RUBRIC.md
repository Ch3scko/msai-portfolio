# Rubric for my page

Each item passes or fails. "How to check" says exactly what to look at, so the answer is never a matter of taste.

| # | Item | How to check | Source |
|---|---|---|---|
| 1 | No template text is left on the page. | Search `index.html` for `CHANGE-ME`, `Your Name`, `placeholder`, `Project one`, `Your role`, `Institution`, `Organisation`. Passes if none appear outside `<!-- -->` comments. | Class rules |
| 2 | My name is spelled the same everywhere. | The tab title, the top badge, the main heading and the photo description all say exactly "Juliana do Espírito Santo". | Template |
| 3 | My photo is mine and small enough. | `photo.jpg` is my headshot, a JPG, under 500 KB. | Class rules |
| 4 | Every image is small enough and in my folder. | Every image the page uses is inside my folder and under 300 KB (except `photo.jpg`, see item 3). | Class rules |
| 5 | Every button and link works. | Every web link starts with `https://` and opens a real page. Every local link (like `resume.pdf`) points to a file that exists in my folder. | Class rules |
| 6 | My one line says what I have done, not a job title. | The quote under my name is one or two true sentences, does not repeat my name, and contains no marketing words ("passionate", "game-changing", "human connection at the center"). | Template, my request |
| 7 | Every project card has three sentences: what it is, what I did, what came out. | Each card's text is exactly three sentences, in that order. | My request |
| 8 | No card title promises more than its text shows. | For each card, everything the title claims (for example, "Predicting") is described as done in the card's text. | FEEDBACK.md (1) |
| 9 | Every card says what stage the work is at. | Each card makes clear whether the work is a plan, an analysis, or a finished, tested tool. | FEEDBACK.md (second comment) |
| 10 | Any data is labelled as real or simulated. | Every card that describes a dataset says whether it is real, anonymised or simulated. | FEEDBACK.md (second comment) |
| 11 | Any relationship in the data says how it was measured. | Every card that says one thing is linked to another names the measure (for example, correlation) and gives the number. | FEEDBACK.md (2) |
| 12 | Every document a card mentions is either linked or marked private. | If a card mentions a document (a workbook, notebook, report), the card links to a public copy, or says it is private or available on request. | FEEDBACK.md (3), second comment |
| 13 | Every number on the page comes from my files. | Each number (dates, percentages, sizes, counts, scores) appears in my CV, my project files, or something I told Claude. | My rule: never invent a fact |
| 14 | Education and Experience match my CV. | Every entry is in my current CV (`resume.pdf`), with the same title, place and dates. Nothing on the page is missing from the CV. | My request |
| 15 | No private details are public. | Neither the page nor `resume.pdf` shows my phone number or home address. | My request |
| 16 | No exclamation marks in the cards. | No `!` appears in any project card. | My request |
